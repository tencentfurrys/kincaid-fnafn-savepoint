2. PATCH IMPLEMENTATION (inputfix\patch_inputfix.py)
    * Maps vaddr -> file offset via PT_LOAD (p_offset + vaddr - p_vaddr);
      does NOT assume off==vaddr. In both libs the third PT_LOAD has
      off != vaddr (arm64: 0xd27920/0xd29920; v7a: 0xb71888/0xb73888), so
      this mattered in principle.
    * Verifies expected prologue at the computed offset, aborts on mismatch.
    * Pre-flight: scans ALL SHT_REL/SHT_RELA sections (arm64: 39,930 relocs;
      v7a: 40,404 relocs) for r_offset inside [func, func+8). NONE found in
      either lib — V2's expectation held; abort would have fired otherwise.
    * Writes:
        arm64 @0x66b848 : e0031f2a c0035fd6  (mov w0,wzr ; ret)
        v7a   @0x4a735c : 0000a0e3 1eff2fe1  (mov r0,#0  ; bx lr)
    * Post-patch sha256 (full):
        arm64: 5fcad54260f97f4542344c634a60fbd94760c7d7a0fc95c80ae2e0e0d1ca7e65
        v7a  : bdd817344cceda0993717e548a8d353e4f19493ab8969eed7d6d8969636b6e46
    * Verified by llvm-objdump: patched entry disassembles to the two
      intended instructions in both libs.
